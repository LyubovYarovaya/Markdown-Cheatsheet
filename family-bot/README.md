# 🏡 Family Hub — телеграм-бот и мини-приложение для семьи

Списки покупок по категориям, вишлисты (общий и личные), учёт трат — всё в одном
Telegram-боте с веб-приложением внутри. Ссылки на товары бот разбирает сам:
вытягивает название, цену и картинку и раскладывает по категориям.

## Что умеет

**🔗 Ссылки → товары.** Кидаешь боту ссылку — он читает страницу (Open Graph и
schema.org), достаёт название, цену, картинку и магазин, определяет категорию по
ключевым словам и кладёт в нужный список. Категорию можно поправить кнопкой под
сообщением.

**🛍 Списки покупок.** Из коробки: Техника, Кухня, Квартира, Текстиль, Baby,
Разное. Свои категории добавляются в приложении. У каждой позиции — цена,
магазин, заметка, статус «куплено», кто добавил.

**🎁 Вишлисты.** Общий на двоих плюс личный у каждого участника. Создаются
автоматически.

**🔗 Публичные ссылки.** Любую категорию (например, Baby) или вишлист можно
открыть по ссылке. Гость заходит с телефона без Telegram, видит список и жмёт
«Забронировать» — остальные видят, что подарок уже занят. Свою бронь можно снять
с того же устройства. **Для личных вишлистов брони скрыты от владельца** —
сюрприз остаётся сюрпризом.

**💸 Траты.** Пишешь боту `450 бензин` или `1200 грн аптека ежемесячная` — он
определяет категорию (машина, здоровье, квартира, продукты, baby, подписки,
одежда, развлечения) и записывает. Траты бывают разовые, ежемесячные,
ежеквартальные и ежегодные. Регулярные платежи заводятся шаблоном и отмечаются
кнопкой «Оплатить». В приложении — сводка по месяцу: итог, разбивка по
категориям, план по регулярным платежам, поддержка нескольких валют.

**👫 Общее пространство.** `/invite` даёт ссылку — по ней вторая половинка
попадает в ту же семью, и списки с тратами становятся общими.

## Быстрый старт

1. **Создай бота** у [@BotFather](https://t.me/BotFather) → `/newbot` → сохрани токен.

2. **Настрой окружение:**
   ```bash
   cd family-bot
   cp .env.example .env       # впиши BOT_TOKEN и PUBLIC_URL
   python -m venv .venv && .venv/bin/pip install -r requirements.txt
   ```

3. **Публичный HTTPS-адрес.** Telegram открывает мини-приложение только по https,
   и по этому же адресу работают ссылки для гостей. Для локального запуска:
   ```bash
   cloudflared tunnel --url http://localhost:8080   # или ngrok http 8080
   ```
   Полученный адрес впиши в `PUBLIC_URL`.

4. **Запусти:**
   ```bash
   .venv/bin/python -m app.main
   ```
   Или в докере: `docker compose up -d --build`.

5. В боте нажми `/start` → «🛍 Открыть приложение». Отправь `/invite` мужу.

Чтобы кнопка меню в Telegram тоже открывала приложение:
BotFather → `/mybots` → бот → *Bot Settings* → *Menu Button* → указать
`https://твой-адрес/app/`.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `PUBLIC_URL` | публичный https-адрес приложения |
| `DATABASE_URL` | по умолчанию SQLite; для Postgres — `postgresql+asyncpg://…` |
| `DEFAULT_CURRENCY` | валюта по умолчанию, `UAH` |
| `BOT_MODE` | `polling` (по умолчанию), `webhook` или `off` |
| `WEBHOOK_SECRET` | секрет для режима webhook |
| `DEV_TG_ID` | **только для локальной отладки**: пускает в API без подписи Telegram |

## Как устроено

```
app/
  main.py            FastAPI + запуск бота (polling или webhook) в одном процессе
  models.py          БД: семьи, пользователи, списки, товары, категории трат, траты
  auth.py            проверка подписи initData из Telegram Mini App
  api/               REST: списки, товары, траты, сводка, публичные страницы
  bot/               хендлеры и клавиатуры aiogram
  services/
    link_parser.py   Open Graph + JSON-LD + микроразметка → название, цена, фото
    categorizer.py   выбор категории по ключевым словам и по пути в URL
    quick_expense.py разбор «450 бензин» → сумма, валюта, категория, периодичность
    items.py         добавление товара (общее для бота и приложения)
    defaults.py      стартовые категории и вишлисты для новой семьи
web/
  index.html app.js  мини-приложение (ванильный JS, тема Telegram)
  share.html share.js публичная страница списка с бронированием
```

Данные разделены по семьям: каждый запрос проверяет, что список или трата
принадлежат семье пользователя. Публичные страницы доступны только по случайному
токену и только пока шеринг включён — выключил, и старая ссылка отдаёт 404.

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Покрыты: подпись initData (валидная, подделанная, просроченная), автокатегории,
парсинг Open Graph и JSON-LD, разбор быстрых трат, сценарии API — создание
семьи, товары, траты и сводка, шеринг с бронированием и скрытие броней от
владельца вишлиста.

## Что можно добавить дальше

- курсы валют, чтобы сводка считалась в одной валюте;
- напоминания о регулярных платежах (бот пишет за пару дней до срока);
- историю цен по ссылке и уведомление, когда товар подешевел;
- экспорт трат в CSV/Google Sheets.
